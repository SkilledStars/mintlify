---
title: "Quickstart"
description: "Your first call in two minutes."
---

<Steps>
  <Step title="Create an API key">
    Open [your API key page](https://fandom-beta-staging.vercel.app/api-keys) (in Fandom: **Settings → API access**) and click **New key**. Choose what it can do, then copy it. The key starts with `fnd_` and is shown once.

    Only workspace admins can create keys.
  </Step>
  <Step title="Make a call">
    Send the key as a bearer token.

    <CodeGroup>
    ```bash curl
    curl https://www.fandom.ai/api/v1/workspace \
      -H "Authorization: Bearer $FANDOM_API_KEY"
    ```

    ```javascript JavaScript
    const res = await fetch("https://www.fandom.ai/api/v1/workspace", {
      headers: { Authorization: `Bearer ${process.env.FANDOM_API_KEY}` },
    });
    console.log(await res.json());
    ```

    ```python Python
    import os, requests

    res = requests.get(
        "https://www.fandom.ai/api/v1/workspace",
        headers={"Authorization": f"Bearer {os.environ['FANDOM_API_KEY']}"},
    )
    print(res.json())
    ```
    </CodeGroup>

    You get the workspace's counts and its latest campaigns.
  </Step>
  <Step title="Create a campaign">
    ```bash
    curl https://www.fandom.ai/api/v1/campaigns \
      -H "Authorization: Bearer $FANDOM_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "name": "Spring launch",
        "campaignType": "DEMAND_GEN",
        "objective": "Reach parents who buy building toys"
      }'
    ```

    The campaign appears in Fandom straight away. Its `url` opens it there.
  </Step>
</Steps>
