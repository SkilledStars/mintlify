## Base URL

```text
https://www.fandom.ai/api/v1
```

<Note>
  **Preview.** Until the next release, this API runs at
  `https://fandom-api-preview.vercel.app/api/v1`. The **Try it** panel in the
  API reference calls the preview.
</Note>

## How it fits together

- A **campaign** belongs to a **brand** and targets one or more **audiences**.
- An audience is built from **data stores**: YouTube channels and videos, with their comments.
- Fandom generates **targeting** for each audience: keywords, segments, topics and websites.
- When it's ready, create the campaign in **Google Ads**. It starts paused.

**Audience Exploration** shows who an audience is on YouTube: the channels they also watch, and how those channels group. It's invite-only for now.
